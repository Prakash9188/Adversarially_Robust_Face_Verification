# Reproducibility declaration

We declare that all results in this repository were produced by the code in this repository,
with the configuration in `configs/default.yaml`, and can be regenerated by following the steps
below. No test-set information was used for tuning: thresholds (and, from Commit 2, detector
parameters) are fitted on the validation/training splits only; splits are identity-disjoint
(asserted in `src/data.py`).

## Artifacts
| Artifact | Location |
|---|---|
| Code | `src/`, `scripts/`, `tests/` |
| Config / seed | `configs/default.yaml` (`seed: 0`) |
| Environment | `requirements-lock.txt` (pip freeze), `environment.yml` |
| Pair protocol | regenerated deterministically from the seed (cached as `data/cache/pairs_*.json`, git-ignored) |
| Results | `experiments/results/*.csv`, `*.png`, `*.log` |
| Commit hashes / timestamps | `docs/commit_log.md` (`python scripts/commit_log.py`) |

## Data and weights (not in the repo)

- Weights: facenet-pytorch VGGFace2 InceptionResnetV1 (no training done by us). Downloaded automatically.

## Known sources of non-determinism
PGD uses a random start (`torch.manual_seed(0)` is set, but results can differ slightly across
hardware/torch versions). Reported numbers come from CPU runs on Windows 11, Python 3.11.9,
torch 2.15.0+cpu.
